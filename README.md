# IN THE MYST

Тактическая стратегическая игра с элементами RPG, разработанная на Java с использованием LWJGL и OpenGL.

## 🎮 Особенности

- **Продвинутая графика**: Использование OpenGL 3.3+, кастомные шейдеры, система частиц, тени, туман войны
- **Тактический геймплей**: Пошаговая/реальновременная боевая система с ИИ противников
- **Процедурная генерация**: Миры создаются с использованием алгоритма Perlin Noise
- **Модульная архитектура**: Чёткое разделение ядра движка и игровой логики
- **Система сохранений**: Сохранение и загрузка прогресса игры

## 🛠 Технологии

- **Язык**: Java 17+
- **Графика**: LWJGL 3, OpenGL 3.3+, GLSL шейдеры
- **Математика**: Собственная библиотека (Matrix4f, Vector3f, Quaternion) + JOML
- **Сборка**: Gradle
- **IDE**: IntelliJ IDEA

## 📋 Требования

- Java JDK 17 или выше
- Видеокарта с поддержкой OpenGL 3.3+
- 2 GB RAM минимум
- Windows/Linux/macOS

## 🚀 Быстрый старт

### Через Gradle (рекомендуется)

```bash
# Запуск игры
./gradlew run

# Сборка проекта
./gradlew build

# Очистка
./gradlew clean
```

### Вручную

1. Убедитесь, что Java 17+ установлена: `java -version`
2. Склонируйте репозиторий
3. Откройте проект в IntelliJ IDEA
4. Запустите главный класс `ru.phoenix.core.CoreEngine`

## ⚙️ Настройка

### Графические настройки

Откройте `src/core/WindowConfig.java` для изменения:
- Разрешения окна
- Полноэкранного режима
- Версии OpenGL
- V-Sync

### Управление

- **WASD** / **Стрелки** - Перемещение
- **Мышь** - Выбор целей, камера
- **Пробел** - Подтверждение действия
- **Esc** - Меню паузы

## 🔧 Разработка

### Добавление новых шейдеров

1. Создайте `.vert` и `.frag` файлы в `src/shaders/`
2. Добавьте загрузку в соответствующий класс ShaderProgram
3. Обновите uniform переменные при необходимости

### Создание новой сцены

1. Расширьте базовый класс `Scene`
2. Реализуйте методы `init()`, `update()`, `render()`
3. Зарегистрируйте сцену в `SceneManager`
